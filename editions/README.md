# Editions and source intake

Place acquired source materials under editions/ without editing the archival originals.

Use REGISTER.csv as the authoritative inventory. Distinguish physical witnesses from modern transcripts and derivative/reference transcriptions.

Suggested storage:

- scans/ — facsimiles or extracted page images
- transcripts/ — supplied electronic transcriptions
- other subdirectories as needed for witnesses/reprints/web references

Every stored file should have provenance and, where practical, SHA-256 recorded in REGISTER.csv or a sibling provenance file.

Do not infer witness independence from filenames or repositories.
