# Proposed terminology and usages

These files preserve range-specific eight-column proposals. They are review candidates, not active glossary assignments. No proposal was promoted into the unchanged 222-entry glossary.

The same Tibetan form can occur in more than one range file because contexts and scoped usage proposals differ. Review the source-linked notes and current glossary before consolidating a primary entry or authorizing any exception. A proposal concerning an existing headword does not overwrite that headword's canonical English.

The corresponding occurrence records are in ../usage/ and the annotated translation. Range reports preserve the translators' reasoning and self-check limitations.
