# Golden-edition workspace

This directory is the working area for the maintained Tibetan edition.

Read guidelines/golden_edition_method.md before substantive work.

Always keep current continuation information in HANDOFF.md and bounded progress in WORK-STATUS.md. WORK-QUEUE.json contains only current finite tasks.

Recommended project-specific additions include:

- source-unit/anchor data
- exact electronic collation
- editorial decision ledgers
- source-review records
- evidence manifests
- reproducible build scripts
- release directories
- validation and negative tests
- publication receipts

Use evidence/ for accepted and exploratory source-image evidence, recovery/ for preserved interrupted states, and tools/ for validators/build helpers.
